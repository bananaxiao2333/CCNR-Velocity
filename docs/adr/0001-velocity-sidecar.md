# ADR-0001 · Velocity 侧车：同步准入 + 有界遥测

- 状态：接受
- 日期：2026-10-23
- 决策者：CCNR

## 背景

准入必须在登录完成前给出结论，因此只能是**同步**调用；但代理的事件线程不能等太久。
遥测是"尽力而为"的数据，丢几条不能影响玩家在线。控制面（CCNR-Data）与代理可能网络分区。

## 决策

1. 插件放在**独立仓库/目录**（`CCNR-Velocity`），不与 CCNR-Data 同仓；契约以 `control.proto` 副本同步。
2. `LoginEvent` 同步调 `AuthorizePlayer`，deadline 1 秒；结果按 UUID 缓存 TTL 秒。
3. 遥测走**有界队列 + 单后台线程**；队列满丢新事件并告警，绝不阻塞游戏线程。
4. 控制面不可达时：在线玩家不受影响；新登录默认拒绝（`fail-open=false`），并给可读原因。
5. 心跳只刷新 `last_seen`，不写事件表；服务端 180 秒无心跳视为离线。

## 后果

- 好处：登录路径可预测（最多多 1 秒）；控制面故障不会雪崩；写入量与在线人数线性而非事件数。
- 代价：网络分区期间新登录被拒；遥测可能丢事件；插件需要自己维护会话状态。
- 重新评估：如果 Velocity 提供异步登录决策 API，或控制面 RTT 稳定超过 1 秒。

# 发布

插件以 **单个 shadowJar** 分发，Gradle 版本号在 `build.gradle.kts` 的 `version`。

## 1. 本地验证

```bash
./scripts/check.sh
```

必须全绿：spotless、编译（`-Werror`）、单测、shadowJar、proto 同步检查。

## 2. 打 tag

```bash
git tag v0.1.0
git push origin v0.1.0
```

CI 的 `release.yml` 会重新跑门禁，并把 `build/libs/*.jar` 附到 GitHub Release。

## 3. 产物

`build/libs/ccnr-control-velocity-<version>.jar`，放进 Velocity 的 `plugins/`。
安装与配置见 [README](../README.md) 与 [03-部署与运维](03-部署与运维.md)。

## 4. 版本约定

- 修复：`0.1.x`
- 新增兼容功能：`0.x.0`
- 破坏配置/协议：升 `x`，并在 CHANGELOG 写迁移说明。
